# AayushOS

Aayush OS — Dynamic Now Bar & Cross-Device Mac Companion Ecosystem for Google Pixel 7 ("panther") & MacBook Air M4.

## Features
- **Dynamic Now Bar V2.4**: Hardware cutout-hugged dynamic island with interactive media, timers, stopwatch, download tracking, and streamlined deck status.
- **On-Device Writing Assist**: Samsung Galaxy AI-style tone rewriter & grammar corrector (`ACTION_PROCESS_TEXT`) powered by local Ollama (`mistral:7b`) with offline fallback.
- **Mac Companion Bridge**: Bidirectional LAN / Tailscale VPN sync, remote screen lock, Find My phone siren, torch toggle, encrypted OTP relay (`ENC_V31`).
- **Zero-Gradle Fast Build Toolchain**: Compiles and deploys directly to Pixel 7 in <2s via AAPT2 and D8.

## Build & Install
```bash
./build.sh
./install.sh
```
